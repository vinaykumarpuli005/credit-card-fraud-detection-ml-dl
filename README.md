# Credit Card Fraud Detection Using Machine Learning and Deep Learning


## Project Overview
This project detects fraudulent credit card transactions using Machine Learning and Deep Learning models.

## Dataset
Dataset used: Kaggle Credit Card Fraud Detection Dataset  
Link: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Note: The dataset file `creditcard.csv` is not uploaded due to file size. It can be downloaded from the Kaggle link above.

The dataset contains credit card transactions labeled as:
- 0: Normal transaction
- 1: Fraud transaction

## Models Used
- Logistic Regression
- Random Forest Classifier
- Neural Network

## Techniques Used
- Data preprocessing
- Feature scaling
- SMOTE for class imbalance
- Model training and comparison
- Model evaluation using Precision, Recall, F1-Score, and ROC-AUC
- Confusion Matrix and ROC Curve visualization

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn
- TensorFlow/Keras
- Joblib

## Conclusion
This project shows how Machine Learning and Deep Learning can be used to detect fraudulent banking transactions. Since the dataset is highly imbalanced, recall and F1-score were important evaluation metrics.
